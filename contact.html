2. What can we help with?

  • Workspace invitations, sign-in, and role-based access.
  • Platform connection status and reporting scope.

3. How to write a useful request

Use the work email associated with the DADTrack account where possible. Include the workspace name, affected page or integration, approximate time, and the outcome you need. Do not include passwords, API keys, access tokens, or full personal data in an email.

For data deletion instructions, see Data deletion. For security reports, see Data & Security.

4. Platform support boundaries

DADTrack is not the operator of Meta, Google, TikTok, AppsFlyer, or another connected platform. Platform approval, account access, billing, attribution definitions, and platform-side deletion requests may need to be handled directly with that provider.
